# Fictional usage scenarios

These are design examples, not real organisations, calls, search findings or executed external tests.

## Care cooperative in Uruguay, ChatGPT Free

First turn asks which assistant is available; the person selects ChatGPT. A separate question identifies the Free plan. The assistant teaches Apps Script, then asks for the project and its activities, materials, and confirmation of the evidence/inference/unknowns summary in successive turns.

The cooperative needs an accessible care facility. It supplies statutes and a budget instead of a website. The assistant does not assume nonprofit status or exclude cooperatives by name. Proposed queries include cooperative care infrastructure grants Uruguay and ayudas cooperativas cuidados Uruguay. Official rules must establish whether building work and equipment are allowed.

## Independent researcher in Senegal, Claude

The person selects Claude, then states their access in a separate turn. They paste the prompt into a normal chat; no Claude Code or skill installation is required. A reduced CV and coastal adaptation project description are supplied voluntarily.

Proposed queries include financement recherche adaptation côtière Sénégal and coastal adaptation research fellowship Senegal. Citizenship, residence and host administration are asked only where missing and relevant. Fellowships are not universally excluded. Without persistent files, the assistant exports the profile and history.

## Municipal museum in Spain, Gemini

The person selects Gemini and later identifies their access. They provide a brochure and digitisation budget. Instructions may optionally be reused in a Gem if available, but this does not establish scheduled execution or history storage.

The legal applicant may be the municipality; this remains pending until confirmed. A scheme restricted to private associations is not suitable without a real eligible route. A call funding only physical conservation does not automatically allow scanners. If APIs are unwanted, the person uses browser queries and a manual sheet.

## Uncertainty and changes

An aggregator says “up to 50,000, closing April”. Currency, award unit, exact date and applicant type stay pending.

A deadline changes for the same official edition: retain its ID, record previous/new values and source, then create a new version. A new edition is a linked new record.

An API returns an error: record a failed/partial run, not no news. Explain the limitation through the available channel or execution log.
